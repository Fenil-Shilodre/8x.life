# 8x.life

> The human company. Human orchestration for business outcomes across 50+ sovereign countries.

Redesigned in the tactile digital craft and editorial posture of [e2.vc](https://e2.vc/).

## Highlights & Features
- **Tactile String Physics Wave Grid**: Real-time quadratic Bezier lines vibrating with cursor proximity and velocity pulses.
- **Clean Aesthetic Hero**: Spacious display typography with interactive Global Orchestration Mesh canvas.
- **Slanted Momentum Card Stream**: Infinite horizontal track featuring 8x verticals and founders with velocity drag inertia.
- **Visual Architecture Pipeline**: 4-tier interactive pipeline detailing intent formulation, machine routing, and human execution.
- **The 8x Machine**: Operational breakdown of all 7 verticals (Social, LinkedIn, Research, Sales, Hiring, Email, Global).
- **The 8x Manifesto**: 2-column interactive navigator exploring the 6 core axioms.
- **Self-Selection Matrix**: Radical transparency filter and 60-second interactive alignment probe.
- **Kinetic Physics Sandbox**: Interactive 2D rigid physics floor with draggable, flingable tokens and collision combos.
- **Elevated Editorial Footer**: 5 live global hub clocks with real-time network latencies and weekly dispatch input.

## Tech Stack
- React 18 + Vite 6
- Tailwind CSS
- GSAP + ScrollTrigger
- Canvas-confetti
- Lucide React

## Getting Started

npm install
